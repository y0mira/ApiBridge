# Code of Conduct

We pledge to make participation in API Bridge welcoming and harassment-free for everyone. Be respectful, assume good intent, accept constructive feedback, and focus discussion on the project.

Unacceptable behavior includes harassment, discriminatory language, threats, doxxing, sexualized attention, and sustained disruption. Maintainers may remove content or participation that violates these expectations. Report conduct concerns privately through the repository owner's contact method. Maintainers will protect reporter privacy as far as practical.

This policy applies in project spaces and when representing the project publicly.
