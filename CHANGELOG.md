# Changelog

All notable changes are documented here. The project follows Semantic Versioning, with the usual `0.x` allowance for documented breaking changes.

- Mock scenarios, fixtures, contract Diff, and real-response validation.
- Shared environment-neutral core package and Node.js 20+ CLI.
