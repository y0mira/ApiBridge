# Security Policy

## Supported version

Security fixes target the latest `0.x` release. Before `1.0`, upgrades may include documented breaking changes.

## Reporting

Use GitHub's private vulnerability reporting feature when it is enabled for the repository. Do not include real API credentials, private OpenAPI documents, or response bodies in a public issue. If private reporting is unavailable, contact the repository owner privately before disclosure.

API Bridge is local-first: the Web application does not upload contracts, fixtures, responses, or settings. The CLI reads local files only and does not fetch remote specifications.
